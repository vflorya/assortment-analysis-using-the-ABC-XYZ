# Проект: Анализ ассортимента методом ABC/XYZ

## Цель  проекта: 
Разработать обоснованные рекомендации по управлению товарным ассортиментом интернет-магазина на основе ABC/XYZ-анализа продаж, выявить SKU-кандидаты на сокращение и оценить потенциальный эффект от оптимизации ассортимента (сокращение около 20% SKU) с учётом рисков для выручки и клиентского опыта.

## Бизнес-задача: 
Оценить структуру ассортимента, определить товары, которые необходимо постоянно поддерживать в наличии, товары, требующие осторожного управления запасами, и товары-кандидаты на вывод. Предложить правила управления товарными позициями и количественно оценить долю SKU и исторической выручки, приходящуюся на кандидатов на сокращение, чтобы минимизировать риски потери выручки и ухудшения клиентского опыта.

## Данные 
Источник данных: UCI Machine Learning Repository — Online Retail II  

`Invoice` - Номер счета / заказа. Используется для подсчета заказов и выявления отмен.    
`StockCode` - Код товарной позиции (SKU). Основной ключ товарного анализа.  
`Description` - Описание / название товара. Нужно для интерпретации результатов.  
`Quantity` - Количество единиц товара в операции. Используется как основа показателя спроса для XYZ.  
`InvoiceDate` - Дата и время операции. Нужна для выбора периода и агрегации по месяцам.  
`Price` - Цена одной единицы товара.  
`CustomerID` - Идентификатор покупателя. Полезен для дополнительных метрик, но не обязателен для ABC.  
`Country` - Страна клиента. Может использоваться в дополнительном анализе.  

Страна: Великобритания  
Валюта: £ - Фунт стерлингов   
Период: 12 полных последовательных месяцев (декабрь 2010 — ноябрь 2011).    

## Инструменты:
Python (pandas, numpy, matplotlib,seaborn), Jupyter Notebook

## Этапы работы:  
1. Знакомство с данными и правила очистки  
   · Анализ размера, типов полей, временного диапазона.  
   · Исследование пропусков, дубликатов, отмен, отрицательных Quantity, нулевых/аномальных UnitPrice, корректности дат и неоднозначных StockCode.  
   · Выбор 12 полных последовательных месяцев, формирование выборки реальных продаж, обоснование правил очистки.  
2. Базовая картина бизнеса  
   · Расчёт уникальных SKU, заказов, покупателей, общего количества единиц и выручки.  
   · Динамика заказов и выручки по месяцам, средний чек на уровне заказа.  
   · Анализ концентрации выручки на небольшой части ассортимента.  
3. ABC-анализ  
   · Агрегация выручки по StockCode, сортировка, расчёт доли и накопительной доли.  
   · Классификация A (≈80% выручки), B (≈15%), C (остальное).  
   · Визуализация кривой Парето, выводы по группам.  
4. XYZ-анализ  
   · Построение месячных временных рядов количества продаж для каждого SKU (с нулевыми месяцами).  
   · Расчёт среднего, стандартного отклонения и коэффициента вариации CV.  
   · Классификация X (CV ≤ 0,5), Y (0,5 < CV ≤ 1), Z (CV > 1).  
   · Учёт новых, редких и сезонных товаров.  
5. Объединённая матрица ABC/XYZ  
   · Соединение результатов по StockCode, присвоение одной из девяти групп (AX…CZ).  
   · Расчёт по каждой группе: количество SKU, доля ассортимента, выручка и её доля, количество единиц, заказов, покупателей, активных месяцев, средняя цена.  
6. Интерпретация и стратегия управления  
   · Формулировка стратегии для каждой группы (приоритет наличия, осторожный запас, проверка роли в ассортименте, кандидаты на вывод).  
   · Обоснование логики на основе данных. 
7. Формирование списка кандидатов на сокращение  
   · Разработка критериев отбора (комбинация ABC/XYZ и дополнительных признаков: заказы, активные месяцы, покупатели, доля выручки, возраст товара).  
   · Формирование итоговой таблицы кандидатов с полями: StockCode, Description, ABC, XYZ, группа, выручка, доля выручки, Quantity, Orders, Customers, ActiveMonths, Recommendation.  
   · Оценка доли SKU и исторической выручки, приходящейся на кандидатов.  
8. Оценка потенциального эффекта  
   · Сопоставление доли сокращаемых SKU и доли их выручки.    
   · Формулировка рисков и ограничений   
   · Указание SKU, требующих ручной проверки.
