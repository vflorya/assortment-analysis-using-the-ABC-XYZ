# Проект: Анализ ассортимента методом ABC/XYZ

# Бизнес-задача: 
Оценить структуру ассортимента и предложить правила управления товарными позициями интернет-магазина подарков и товаров для дома.  
Главный вопрос проекта. Какие товары необходимо постоянно держать в ассортименте, какие требуют осторожного управления запасами, а какие можно рассматривать как кандидатов на сокращение или вывод – и какой потенциальный эффект даст такое решение?  

# Данные 
Источник данных: UCI Machine Learning Repository — Online Retail II  
`Invoice` - Номер счета / заказа. Используется для подсчета заказов и выявления отмен.    
`StockCode` - Код товарной позиции (SKU). Основной ключ товарного анализа.  
`Description` - Описание / название товара. Нужно для интерпретации результатов.  
`Quantity` - Количество единиц товара в операции. Используется как основа показателя спроса для XYZ.  
`InvoiceDate` - Дата и время операции. Нужна для выбора периода и агрегации по месяцам.  
`Price` - Цена одной единицы товара.  
`CustomerID` - Идентификатор покупателя. Полезен для дополнительных метрик, но не обязателен для ABC.  
`Country` - Страна клиента. Может использоваться в дополнительном анализе.

# Этапы работы:
1. Загрузка библиотек и данных
2. Предобработка данных
3. Определение основных метрик: Уникальные SKU, заказы, покупатели, проданные единицы, выручка, средний чек
4. АВС - анализ: посчитали выручку по каждому SKU
5. XYZ- анализ: показали насколько стабильно товар продается по месяцам.

# Подходы решения бизнес-задачи
**1. ABC-анализ**
ABC-анализ в этом проекте используется для оценки экономической значимости товара. Базовая метрика – выручка за выбранный период.  
Принцип Парето соблюден: 22.2% ассортимента (866 SKU) приносят 80% выручки.  
998 SKU (25.6% ассортимента) приносят всего 0.37% выручки. Это явные кандидаты на вывод.  
443 SKU (11.4%) продались тиражом менее 10 единиц за год, дав всего 0.11% выручки. Это «мертвый» или почти мертвый запас.  
При этом топ-10 товаров (вроде REGENCY CAKESTAND 3 TIER и WHITE HANGING HEART T-LIGHT HOLDER) — это «звезды», которые нельзя терять ни в коем случае.  

**2. XYZ-анализ**
XYZ-анализ в проекте нужен для оценки вариативности физического спроса.
